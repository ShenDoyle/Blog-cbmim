# Notion 内容后台 · 结构与导入设计

> 状态：**待执行**。需要 Notion 连接器的工具在会话内可用后，由 Claw 在 Notion 里创建并导入。
> 本文档用于事先确认结构，避免建完再改。

## 一、目标结构（Notion 里长这样）

Notion 没有文件夹，用**父页面**当"文件夹"：

```
CBMIM 博客（父页面 = 你说的"文件夹"）
├── 📝 博文              ← 数据库（唯一被每日同步的对象）
├── 📄 页面              ← 数据库（关于 / 版权 / 隐私 等自写页面）
└── 📎 站点数据          ← 数据库（友链 / 好东西，后期接入）
```

## 二、数据库字段设计（博文）

| 字段名 | 类型 | 对应 Hexo 字段 | 说明 |
|---|---|---|---|
| 标题 | 标题 | `title` | 必填 |
| Slug | 文本 | 文件名 | 锁定后不改，保 URL 稳定 |
| 日期 | 日期 | `date` | 东八区 |
| 分类 | 多选 | `categories` | |
| 标签 | 多选 | `tags` | |
| 封面 | 文本(URL) / 文件 | `cover` | 留空则该篇无封面 |
| 摘要 | 文本 | `description` | `<!--more-->` 前的描述 |
| 置顶权重 | 数字 | `top_group_index` | 0 = 不置顶 |
| 发布 | 复选框 | — | 取消勾选 = 从站点移除该篇 |
| 页面ID | 文本 | `notion_page_id` | 回写用，**不要手改** |

可选 4 个字段（配合封面蒙版脚本 `scripts/covermeta.js`）：`封面标题` / `封面副标题` / `蒙版强度` / `封面底图`。

## 三、写作规范（Notion → 站点的转换规则）

| 在 Notion 里写 | 站点上变成 |
|---|---|
| 高亮块 Callout（灰/棕） | `{% note default %}` |
| Callout（蓝 / 绿 / 黄 / 红） | `{% note info / success / warning / danger %}` |
| 折叠列表 Toggle | `{% hideToggle 标题 %}` |
| 分割线放在正文某处 | 该位置成为摘要截断点（`<!--more-->`），之后为「阅读全文」 |
| 图片 | 自动下载到 `source/img/<slug>/`，引用改为 jsDelivr CDN |
| 代码块 / 表格 / 引用 / 待办 | 原生 markdown 对应语法 |

⚠️ Notion 图床链接 **约 1 小时过期**，必须由脚本下载落地——这一步已自动处理。

## 四、独立页面（"其它自己写内容的子页面"）

分三档，按性价比排：

| 档位 | 页面 | 现在的内容在哪 | 处理方式 |
|---|---|---|---|
| **① 直接纳入**（纯文本，零风险） | 版权协议 `/cc/`、隐私政策 `/privacy/`、关于页正文 `/about/` | `source/<页>/index.md` 正文 | 进「📄 页面」数据库，Notion 改完同步回 md |
| **② 部分纳入** | 关于页的卡片信息（头像 / 技能标签 / 签名） | `source/_data/about.yml` | 后期用「站点数据」库管理，脚本生成 YAML |
| **③ 暂不纳入** | 音乐馆 `/music/`、标签 `/tags/`、分类 `/categories/` | 主题配置自动生成 | 无自由文本，Notion 化了也没意义 |
| **③ 暂不纳入** | 友链 `/link/`、好东西 `/equipment/` | `source/_data/link.yml`、`equipment.yml` | 结构化数据，量大；第二期再做 |

## 六、导入后的一致性保障

- 文件名 / Slug **锁定**，与站点 URL 一一对应，不因 Notion 标题改动而变化
- 增量同步依据 `last_edited_time`，状态记录在 `.notion-sync-state.json`
- **只增改、不自动删除**——Notion 里删掉一篇，站点上那篇会保留（要删得手动勾掉「发布」或本地删文件）
